# 🚗 Velocity Racer

**Velocity Racer** is a modern **2D browser racing game** built using **HTML, CSS, and JavaScript**.  
Drive through an endless highway, dodge enemy cars, and survive as long as possible while your score keeps increasing.

---

## 🎮 Gameplay

The objective is simple: **avoid collisions and survive the traffic.**

Control your car using the keyboard and navigate through the road while enemy vehicles appear from the top.

---

## 🕹 Controls

| Key | Action |
|----|------|
| ⬆ Arrow Up | Move Forward |
| ⬇ Arrow Down | Move Back |
| ⬅ Arrow Left | Move Left |
| ➡ Arrow Right | Move Right |

---

## ✨ Features

- 🚗 Smooth car movement
- 🛣 Infinite scrolling road
- 🚙 Random enemy cars
- 💥 Collision detection system
- 📊 Live score tracking
- ⚡ Lightweight and fast gameplay
